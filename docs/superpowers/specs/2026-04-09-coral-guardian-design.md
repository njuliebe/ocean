# 珊瑚守护者 v2 — 设计文档

## 概述

面向儿童的海底珊瑚保护教育 SPA 应用。玩家使用工具探测和修复生病的珊瑚，全部修复后完成任务。视觉追求真实震撼的海底世界效果，交互简单直觉化。

## 技术方案

**混合渲染架构**：Three.js 负责海洋环境渲染，珊瑚用高清 PNG 图片叠加在场景上，UI 用原生 HTML/CSS。

### 分层结构

| 层级 | 技术 | 内容 |
|------|------|------|
| 底层 | Three.js WebGL Canvas | 海水着色器、体积光束、焦散光斑、气泡粒子、浮游微粒、海底沙地 |
| 中间层 | HTML absolute 定位 | 珊瑚 PNG 图片，CSS 动画实现轻微摇摆 |
| 顶层 | HTML/CSS | 工具栏、进度条、语音气泡、珊瑚信息面板 |
| 特效层 | Canvas 2D overlay | 修复粒子特效（营养液喷洒、清洁泡泡、冰晶降温） |

### 依赖

- Three.js v0.170.0（CDN importmap，唯一外部依赖）
- 零构建工具，纯 ES Module
- 本地 `file://` 可直接打开，也可部署到任意静态服务器

## Three.js 海洋环境

### 效果清单

1. **水体着色器** — 深蓝到浅蓝的深度渐变，顶部微弱波纹折射
2. **体积光束** — 从水面射入的阳光光柱，缓慢摆动（3-4 束）
3. **焦散光斑** — 海底地面上的波纹光斑，随时间缓慢流动
4. **气泡粒子** — 随机上浮，带横向正弦漂移和透明度变化（50-80 个）
5. **浮游微粒** — 细小发光点缓慢飘动，增加水体真实度（30-50 个）
6. **海底沙地** — 接收焦散光斑投影的平面

### 相机

- 固定视角，略微俯视海底
- 无 OrbitControls（面向儿童，避免迷失方向）
- 可选：鼠标轻微视差效果（移动鼠标时场景微微偏移）

## 珊瑚系统

### 珊瑚数据（5 个）

| # | 名称 | 问题类型 | 生病表现 | 修复工具 | 健康颜色 |
|---|------|----------|----------|----------|----------|
| 1 | 脑珊瑚 | 营养不良/白化 | 灰白色，失去光泽 | 💧 营养液 | 粉红色 |
| 2 | 鹿角珊瑚 | 营养不良/白化 | 完全变白 | 💧 营养液 | 鲜红色 |
| 3 | 海扇珊瑚 | 垃圾覆盖 | 垃圾图标附着，颜色暗沉 | 🧹 清理 | 紫色 |
| 4 | 柱状珊瑚 | 温度过高 | 泛红，周围热浪效果 | 🌡️ 调温 | 青绿色 |
| 5 | 蘑菇珊瑚 | 垃圾覆盖 | 污泥覆盖，暗黄 | 🧹 清理 | 金黄色 |

### 珊瑚图片

- 来源：Unsplash / Pexels 等免费素材网站
- 格式：PNG 透明背景
- 每个珊瑚准备健康态图片，生病态通过 CSS filter 实现（grayscale、hue-rotate、brightness）
- CSS 动画：轻微左右摇摆（模拟水流），周期 3-5 秒

### 问题视觉标记

- **营养不良/白化**：CSS `filter: grayscale(1) brightness(1.3)` 使图片变灰白
- **垃圾覆盖**：珊瑚图片上叠加垃圾 emoji/图标（🗑️🥤🛍️），CSS filter 降低饱和度
- **温度过高**：CSS `filter: hue-rotate(-30deg) saturate(2)` 偏红 + 红色发光阴影 + 热浪 CSS 动画

## 交互系统

### 双模式交互

**模式 A — 先选工具再点珊瑚：**
1. 工具栏选中工具（高亮显示）
2. 点击珊瑚执行对应操作
3. 探测工具：弹出语音气泡，播报珊瑚问题
4. 修复工具：匹配则执行修复动画，不匹配则提示"这个工具不对哦"

**模式 B — 直接点珊瑚：**
1. 点击珊瑚弹出信息面板
2. 面板显示：珊瑚名称、问题描述、可用工具按钮
3. 正确工具高亮可点击，错误工具灰显不可点击
4. 点击正确工具执行修复

### 工具栏

| 工具 | 图标 | 功能 |
|------|------|------|
| 探测 | 🔍 | 检测珊瑚问题，触发语音播报 |
| 营养液 | 💧 | 修复营养不良/白化 |
| 清理 | 🧹 | 清除垃圾/污泥 |
| 调温 | 🌡️ | 降低过高温度 |

## 修复动画

### 粒子特效

- **💧 营养液**：蓝绿色水滴粒子从上方飘洒，持续 2 秒
- **🧹 清理**：白色清洁泡泡从珊瑚表面升起 + 垃圾图标飘走消失
- **🌡️ 调温**：❄️ 冰晶粒子环绕珊瑚旋转，红色光晕消退

### 颜色恢复

- CSS transition 2 秒，filter 从生病态渐变到健康态（`filter: none`）
- 恢复后短暂发出柔和光芒（box-shadow 脉冲动画）

### 完成庆祝

- 全部 5 个珊瑚修复后触发
- 彩色粒子烟花效果
- 鱼群动画游过场景
- 全屏庆祝面板 + 语音"恭喜你，所有珊瑚都恢复健康啦！"
- "再玩一次"按钮

## UI 设计

### 整体风格

- 深海蓝主题色
- 磨砂玻璃效果（`backdrop-filter: blur`）
- 圆角卡片式组件
- 童趣但不幼稚，高级现代感

### 顶部栏

- 左侧：🐠 + "珊瑚守护者" 标题
- 右侧：修复进度条 + 数字（如 2/5）
- 半透明磨砂背景，固定在顶部

### 底部工具栏

- 居中浮动，圆角胶囊形
- 磨砂玻璃背景 + 细边框
- 4 个工具按钮，选中态有蓝色高亮边框和背景
- 每个按钮：emoji 图标 + 中文标签

### 语音气泡

- 探测珊瑚后在页面上方浮现
- 磨砂背景 + 蓝色边框
- 左侧 🔊 图标 + 右侧文字内容
- 3 秒后自动淡出

### 珊瑚信息面板

- 直接点击珊瑚时弹出
- 磨砂背景卡片，显示珊瑚名称、问题、描述
- 底部工具按钮行，正确工具高亮

## 语音系统

- Web Speech API（SpeechSynthesis）
- 中文语音
- 探测时播报："这个{珊瑚名称}{问题描述}，需要{工具名称}来修复哦！"
- 修复成功时播报："{珊瑚名称}恢复健康啦！"
- 全部完成时播报："恭喜你，所有珊瑚都恢复健康啦！你是最棒的珊瑚守护者！"

## 性能考虑

- Three.js 只渲染环境效果，不渲染珊瑚几何体，GPU 负担轻
- 粒子数量控制在合理范围（气泡 50-80，浮游 30-50）
- 珊瑚图片预加载，带 loading 界面
- CSS 动画用 `transform` 和 `opacity`，触发 GPU 加速
- 修复粒子特效用完即销毁
